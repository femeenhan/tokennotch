# 픽셀 대시보드 사용법

메뉴 막대의 불꽃 아이콘 → **대시보드 열기…**로 엽니다. 캐릭터 중앙을 클릭하면 일반 Codex의 남은 사용량을 보여주는 작은 요약 패널이 열립니다. 창을 닫아도 앱·캐릭터·이벤트 수신은 계속됩니다. 캐릭터 관리 메뉴는 캐릭터 중앙 우클릭 또는 메뉴 막대 불꽃에서 엽니다.

## 제공자 전환

헤더에서 별도 타이틀 없이 Codex·Claude·Gemini·Grok을 선택한다. 정령은 제공자마다 하나이며 화면에는 최대 세 개를 표시한다. 정령 클릭 요약과 우클릭 메뉴에서 대시보드를 열면 해당 제공자를 선택한다. Codex의 계정 한도·일별 토큰은 Codex 화면에만 표시한다. 다른 제공자는 관측한 작업 상태·세션 수·도구 활용과 계정 사용량 조회 미지원을 표시한다. 숨겨도 이벤트 수집은 계속된다. 설정 경로와 지원 제한은 [제공자별 정령](providers.md)을 참고한다.

## 캐릭터 클릭 요약

요약은 캐릭터 옆에 붙는 240×156 크기의 테두리 없는 픽셀 말풍선입니다. 각진 모서리와 계단형 꼬리 바깥은 투명하며, 화면 가장자리에서 잘리지 않도록 필요하면 좌우를 뒤집습니다. 일반 Codex 계정의 주간 잔여량과 짧은 픽셀 게이지, ‘대시보드 열기’ 버튼만 표시합니다. 본문 제목·새로고침 버튼·리셋 시각·소모 추세·정령 메뉴는 넣지 않습니다. 잔여량을 확인하지 못한 경우에는 0으로 대신 표시하지 않으며, 새 조회가 확인되지 않은 값에는 ‘이전 값’을 짧게 표시합니다.

캐릭터를 다시 클릭하거나 말풍선 밖을 클릭하거나 Esc 키를 누르면 닫힙니다. ‘대시보드 열기’를 눌러도 말풍선은 닫히고 상세 창이 열립니다.

Spark 등 별도 한도는 일반 주간 잔여량과 합치지 않습니다. 별도 한도, 리셋 시각과 추세 등 자세한 정보와 조회 제어는 대시보드에서 확인합니다. 요약 패널을 연 뒤에도 기존 자동 조회 설정과 간격을 따릅니다.

## 계정 한도 (첫 화면)

기본 창은 960×740이며 최소 크기는 880×620입니다. 한도 패널은 제공된 각 모델·기간을 같은 폭의 열로 배치하고 잔여율을 모두 32pt로 표시합니다. 카드 아래에는 잔여량 추세와 사용량 히트맵을 배치하고, 히트맵 옆에서 일평균·누적 사용량을 확인합니다. 소비 내역과 API 환산 참고액은 표시하지 않습니다. 주간·5시간 한도 막대는 모두 8pt 두께입니다. 창을 줄이면 스크롤할 수 있습니다.

별도 로그 선택 없이 로그인된 Codex CLI의 계정 한도를 자동 조회합니다. 기본 간격은 약 60초이고 앱 시작·패널 열기·새로고침에서도 조회합니다. 중복 조회는 하지 않으며 연속 새로고침은 최소5초 간격입니다. macOS 절전·잠금 중에는 정기 조회를 멈춥니다. 메뉴 막대 불꽃 옆 숫자는 일반 Codex의 주간 잔여율입니다.

Astra·Sol 일반 한도와 Spark 별도 한도를 같은 비중의 열로 표시합니다. 잔여율과 리셋까지 남은 시간을 표시하며 정확한 로컬 리셋 시각은 툴팁으로 제공합니다. 한도 길이를 실제 응답에서 읽어 300분=5시간, 1440분=일간, 10080분=주간으로 식별하며 응답 순서로 기간을 추정하지 않습니다. 없는 5시간·일간 항목은 공간을 차지하지 않습니다. 일반 한도는 Astra·Sol이 공유하며 Spark와 합치지 않습니다. 잔여 비율은 실제 작업 실행 허용 여부를 보장하는 표시가 아닙니다.

마지막 확인 시각을 표시합니다. 재실행 후 새 조회 성공 전, 조회 실패·중지, 마지막 성공 이후3분이 지나면 ‘이전 관측값’ 또는 중지 상태를 표시합니다. 리셋 예정 시각이 지났다고 임의로100%를 만들지 않고 새 조회를 기다립니다. 자동 조회는 설정에서 중지할 수 있습니다. API키 로그인만 있는 경우 등 계정 한도를 제공하지 않는 환경에서는 로그인·연결 안내를 표시합니다.

## 주간 소모 추세

최근8일의 계정 한도 관측 메타데이터를 로컬 `quota-history.json`에 보관합니다. ‘오늘 관측 감소’는 오늘의 첫 관측부터 최신 관측까지 사용률 증가이며, 자정 이후 전체 사용량이라고 추정하지 않습니다. ‘최근 관측 감소’는 최근60분 안의 실제15분 이상 관측 구간입니다. 단위 `%p`는 퍼센트포인트입니다(잔여50%→45%이면5%p 감소).

그래프는 최근60분의 **잔여율**을 Astra·Sol 공유 한도와 Spark 각각 표시합니다. 세로축은 표시한 퍼센트 범위로 확대하고 가로축은 실제 관측 시각입니다. 모델명 옆에 감소 퍼센트포인트를 표시합니다. 예를 들어31%→28%는3%p 감소이며,97%→97%는‘변화 없음’입니다. 각 그래프의 축 범위가 달라 선의 높이·기울기를 모델 간 절대 사용량으로 비교하지 않습니다. 최소4%p 범위를 사용해 작은 흔들림을 과장하지 않습니다. 확대 축 설명과 관측 조건은 툴팁으로 제공합니다. 같은 리셋 구간의 연속 관측2회가 없으면‘관측 대기’이며,5분 넘는 공백·누락·리셋 변경·시간 역전·잔여율 상승 구간은 연결하지 않습니다.

같은 계정·같은 주간 리셋을 확인한 관측만 비교합니다. 계정 변경 시 추세 이력은 새 계정의 관측으로 교체하며, 계정식별 정보 미제공·관측중간의 한도누락·리셋변경·사용률감소가 있으면 해당 구간을 비교하지 않습니다. 여러 모델·세션의 사용이 계정 한도에 함께 반영되므로 특정 모델/세션/MCP의 소모라고 나누지 않습니다.

30분 이상 충분한 관측과 안정적인 증가가 확인되면 현재 속도가 유지된다는 조건 아래 리셋 전 소진 위험을 안내합니다. 이는 확정 예측이나 전환 명령이 아닙니다. Astra/Sol 전환이나 추론 강도는 사용자가 선택합니다. 초기에는 ‘관측 대기’가 정상이며, 새 조회가 오래되거나 저장에 실패하면 위험 안내를 표시하지 않습니다.

## 도구 활용

두 번째 탭은 선택기간의 MCP 도구 완료 이벤트와 mcp/shell/fileEdit/agent/other 범주별 관측 횟수를 표시합니다. 현재 훅은 서버·도구 이름, 실행 결과, 스킬 실행 근거를 보존하지 않습니다. Skills는 ‘실행 관측 미지원’으로 표시하며 설치 수를 사용 횟수로 바꾸지 않습니다. 앱이 꺼져 있을 때의 도구 이벤트는 소급 복구하지 않습니다.

## 히트맵과 일평균 소비

계정의 `account/usage/read`에서 제공된 일별 토큰을 26주 격자로 표시합니다. 파일 선택은 필요 없습니다. 셀에 마우스를 올리면 날짜·토큰 수를 확인합니다. 빈 테두리는 미제공이며 실제 0과 구분합니다. 제공된 날짜 기준을 유지하며 과거 26주가 모두 반환된다고 보장하지 않습니다. 제공된 일별 값은 계정별로 최대182일분 보관합니다. 계정이 바뀌면 이전 계정의 일별 표시를 비웁니다.

오늘·7일·30일 선택은 일평균 소비에 적용됩니다. 일평균은 선택 기간 중 **기록이 제공된 날짜 수**를 분모로 사용하고 그 날짜 수를 표시합니다. 미제공 날짜를 0으로 만들어 평균을 낮추지 않습니다.

## 기술 진단

UUID·원시 이벤트 중심의 ‘상세 기록’ 탭과 수동 프로젝트 분류 화면은 제거했습니다. 기존 로컬 데이터는 유지합니다. 연결 상태와 진단 JSON 내보내기는 설정의 ‘기술 진단’에서 접근합니다. 도구 완료 수는 성공 횟수가 아닌 `toolFinished` 이벤트 수입니다.

## 토큰 사용량

기본값은 수집 안 함입니다. 설정의 ‘사용량 로그 연결…’에서 동의 후 Codex 세션 JSONL 파일 한 개를 직접 선택합니다. 선택한 파일의 기존 토큰 기록과 이후 추가되는 기록을 약5초 간격으로 관측합니다. 홈·세션 폴더 전체를 검색하지 않으며 선택 파일은 재실행 후 다시 선택해야 합니다.

지원 형식은 Codex의 `session_meta.payload.id`, `turn_context.payload.model`, `event_msg.payload.type = token_count`와 `info.total_token_usage`입니다. 공개 소스의 현재 형식에 맞춘 파서이며 안정적인 외부 API 계약은 아닙니다. 미지원·잘못된 기록은 제외하고 상태를 표시합니다. `last_token_usage`만 있는 기록은 세션 전체 누적값으로 간주하지 않습니다.

진단용 로그 데이터는 검증된 누적값 사이의 증가분만 날짜·모델별로 합산합니다. 대시보드에는 소비 내역을 표시하지 않습니다. 최신 누적값은 별도로 유지하며 증가분에 더하지 않습니다. 첫 누적값, 카운터 감소, 압축 경계, 감지한 관측 공백과 모델 혼합 구간은 상세 합계에서 제외합니다. 날짜는 토큰 **보고 시각** 기준입니다. 원본 파일 재선택·재시작·복사본 가져오기에서 같은 증가분의 중복을 제거합니다. 서로 다르게 편집한 발췌본의 겹치는 구간까지 자동 조정하지는 않습니다.

캐시 읽기는 입력에, 추론 출력은 출력에 포함됩니다. 캐시 쓰기는 미수집입니다. 미수집은 0이 아닙니다. ‘수집 중지’는 새 읽기를 중지하며 기존 기록은 유지합니다. 저장 실패 기록은 앱이 켜져 있는 동안 메모리에 보관하고 다음 관측에서 재시도합니다.

## 저장과 내보내기

정규 실행의 이벤트 데이터는 `~/Library/Application Support/BuildSpirit/dashboard.sqlite`에 로컬 저장됩니다. 실제 위치는 앱의 이벤트 소켓과 같은 폴더이며 테스트의 `--socket` 옵션에서는 별도 위치를 사용합니다. SQLite WAL 파일이 함께 있을 수 있습니다. 이벤트 ID 중복을 제거합니다. 명령·프롬프트·응답·코드·파일 내용은 저장하거나 전송하지 않습니다. JSON 내보내기는 설정에서 접근하며 등록한 프로젝트의 절대 경로를 포함하므로 외부 공유 전 확인하세요. 계정 한도 이력은 같은 폴더의 `quota-history.json`에 비공개 파일권한으로 저장하고 내보내기에는 포함하지 않습니다.

앱이 꺼져 있을 때의 훅 이벤트는 복구하지 않습니다. 실제 청구액·Git 통계는 포함하지 않습니다. Claude·Gemini·Grok은 CLI 작업 상태 연결만 제공하며 계정 사용량 조회는 지원하지 않습니다. 아직 서명된 설치 패키지나 공개 배포 버전은 아닙니다.

## 디자인과 검증

[MakeBead 참고 화면](https://makebead.com/ko/patterns/p/red-rose-34e6879bb7fdb014)의 각진 경계·픽셀 타이포 방향을 기존 정령에 맞췄습니다. 한국어 제목은 [Neo둥근모 v1.600](https://neodgm.dalgona.dev/downloads/neodgm.html)을 사용하며 SIL OFL 라이선스 전문을 앱의 `Spirit/Fonts/LICENSE.txt`에 포함합니다. 폰트의 macOS 경계 높이 문제를 우회해 AppKit으로 제목을 그리며 접근성 레이블을 제공합니다. 본문과 버튼은 시스템 글꼴입니다.

자동 검증: 코어 Swift 테스트, 브리지·앱 훅·대시보드 저장/재실행·계정 한도 연결 통합 테스트, 밝은/어두운 모드의 한국어 픽셀 제목 렌더링 테스트. 모델별 불변 증가분과 누적값의 중복 합산 방지, 날짜 경계, 미분류 구간 제외, 캐시·추론 이중 계산 방지를 검증합니다. `Tests/DashboardUsageSmoke.swift`는 Astra·Spark 한도와 소비 내역을 제거한 화면을 두 모드로 렌더링합니다.

실제 앱에서 한도 카드, 자동 갱신, 계정 일별 히트맵과 기간 전환, 설정의 수집·진단 접근을 확인했습니다. 밝은/어두운 사용량 화면도 실제 앱에서 확인했습니다. 실제 응답에서 발견한 최대5초 reset시각 흔들림과 정수단위 사용률의 계단식 증가를 추세 계산 회귀로 검증합니다.


### 대시보드 시각 규칙

제공자·탭·집계 기간은 높이 28pt의 각진 선택 버튼과 동일한 선택 표시를 사용합니다. 섹션 제목은 16pt 픽셀, 주요 수치는 32pt 픽셀, 본문·컨트롤은 12pt, 보조 정보는 11pt입니다. 패널은 1pt의 옅은 테두리와 14pt 내부 여백을 사용하며 그림자는 두지 않습니다. 색은 따뜻한 중립 배경과 주황 강조색으로 통일했습니다. ‘오늘·7일·30일’은 일평균 옆에 배치해 최근 26주 히트맵과 집계 범위를 구분합니다.

렌더링 검증은 일반 한도 3개·한도 4개·기록 없음 상태를 각각 880×620 및 960×740, 밝은·어두운 모드에서 실행합니다.
