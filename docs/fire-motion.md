# 불의 정령 동작

작업 중 열기와 잔여 한도에 따른 활력을 독립적으로 표현한다. 작업 시작 시 불꽃이 솟고, 타격에 반짝이며, 종료 후 약 20초 동안 잔열이 서서히 줄어든다. 완료 시 점프와 원형 불티가 발생한다. 확인 필요 상태에서는 손 위에 불씨를 내민다.

잔여 한도 50% 이상은 정상 활력이며, 그 아래에서는 중심부와 불꽃 끝의 열기가 줄고 전용 반쯤 감긴 픽셀 눈으로 피로를 표현한다. 얼굴 비율과 몸체 불투명도는 유지한다. 한도 소진 시 대기 상태에서 잔불처럼 쉰다. 관측 한도가 15%p 이상 증가하면 기지개와 불꽃 회복 제스처가 발생한다. Codex의 최신 한도 중 가장 적게 남은 기간을 사용한다. 다른 제공자와 오래된/미확인 관측값에는 정상 활력을 적용한다.

캐릭터 공간에서 주변 커서를 매 프레임 읽어 시선과 고개를 움직인다. 빠른 통과는 불꽃을 바람처럼 휘게 하며, 머리 위에서 천천히 움직이면 눈을 가늘게 뜨고 불티를 낸다. 빠른 접근은 최소 4초 간격으로 움찔 반응한다. 기존 클릭/드래그 입력 영역은 유지한다.

대기 중 12초 이후 불씨 잡기, 불꽃 정돈, 불꽃 하품을 서로 다른 간격에 보여준다. 세 동작을 한 차례씩 보인 뒤 순서를 섞는다. 55초 이상 대기하면 망치를 얼굴 아래 옆으로 내려놓고 전용 감은 눈으로 졸기 시작한다. 휴식 자세는 부드럽게 전환하며 진행 중인 망치질을 마친 뒤 적용한다. 동작 줄이기 설정은 모션과 불티를 모두 멈추고 정적인 색과 체력 표현을 유지한다.

설정의 정령 동작 확인 창에서 7가지 상태, 잔여 한도, 느리게 보기, 동작 줄이기를 확인할 수 있다. 이어보기에는 상태별 동작과 한도 감소/회복이 포함된다.

세션 미관측 물음표는 표시하지 않는다. 나머지 상태 표시는 몸체와 겹치지 않도록 이름표 옆에 배치한다.

검증: SpiritCore 테스트 166개, Xcode Debug 빌드, 실제 SpriteKit 렌더링 검사 및 상태별 PNG 11장과 128·192pt × 정상·피로·소진·휴식 × 밝은·어두운·패턴 배경 비교 PNG 24장. 별도 lint 설정은 없으며 Swift 빌드가 타입 검사를 수행한다.


## 말풍선과 날아가는 불꽃

상태가 바뀌면 작은 크림색 픽셀 말풍선으로 작업·확인 요청·완료·인사·오류·휴식을 설명한다. 말풍선 또는 캐릭터를 클릭하면 닫히고 동일 상태 갱신으로 다시 나타나지 않는다. 완료·인사 동작이 끝나도 말풍선은 클릭할 때까지 유지한다. 말풍선을 닫은 다음 캐릭터 클릭은 기존 사용량 요약을 연다. 숨김과 이동은 캐릭터를 따라가며 화면 경계에서 좌우 배치를 바꾼다. 동작 확인 창에서도 같은 말풍선을 클릭해서 닫을 수 있다.

날아가는 불꽃은 주황 외곽·노란 중심·크림색 불씨를 가진 7×11 픽셀 형태와 짧은 꼬리로 표현한다. 머리 양옆에서 바깥으로 떠오르고 이동 방향에 따라 기울며, 또렷하게 유지한 뒤 작아지며 사라진다. 망치 타격과 완료 효과에도 같은 형태를 사용한다. 동작 줄이기는 날아가는 효과를 제거한다.

추가 검증: 네이티브 말풍선 클릭, 상태 반복 갱신, 다음 상태 재표시, 완료 후 유지, 숨김·이동, 기존 클릭·우클릭·드래그 입력, 실제 128·192pt 불꽃 렌더링.


## 충전·변신·드래그

일반 클릭은 말풍선 닫기·사용량 요약을 유지한다. 0.75초 이내 간격으로 세 번 이상 클릭하면 충전하고, 0.45초 이상 누르기 시작해서 약 1.8초 유지하면 최대 충전에 도달한다. 불꽃 끝이 커지고 후광이 생기며 황금색에서 푸른색으로 바뀐다. 원래 파츠의 외곽·중심·밝은 영역을 별도 팔레트로 변환해 명암과 픽셀 실루엣을 유지한다. 충전 후 손을 떼면 요약 창을 열지 않으며 충전 말풍선이 나타난다. 반복 클릭으로 이미 열린 요약 창은 변신 시 닫힌다. 충전은 서서히 해제된다.

불꽃 배출 지점은 왕관·머리 옆·어깨·발의 11개 지점을 번갈아 사용한다. 충전 시 배출량도 증가한다. 드래그 속도에 따라 불꽃이 뒤로 휘고 위아래 이동에 따라 길어진다. 드래그 자체는 충전을 시작하지 않으며, 먼저 충전한 뒤 드래그하는 것은 가능하다.

드래그 잔상은 클릭을 통과하는 384pt 효과 창에서 화면 좌표를 유지하며 약 0.48초 후 사라진다. 이동 전후 위치 사이에서 불꽃을 만들어 단순한 창 이동 대신 불꽃이 흐르는 인상을 준다. 변신 색상을 따르며 개수는 96개로 제한한다. 숨김 시 정리하고 동작 줄이기에서는 잔상을 표시하지 않는다.

동작 확인 창의 불꽃 충전 체크로 변신을 미리 볼 수 있다. 검증: SpiritCore 168개 테스트, 네이티브 길게 누르기와 기존 클릭 검사, 실제 128·192pt 황금·푸른 변신 렌더링, 다양한 배출 지점과 동작 줄이기 검사, 앱 빌드.
