# 불의 정령 동작

작업 중 열기와 잔여 한도에 따른 활력을 독립적으로 표현한다. 작업 시작 시 불꽃이 솟고, 타격에 반짝이며, 종료 후 약 20초 동안 잔열이 서서히 줄어든다. 완료 시 점프와 원형 불티가 발생한다. 확인 필요 상태에서는 손 위에 불씨를 내민다.

잔여 한도 50% 이상은 정상 활력이며, 그 아래에서는 중심부와 불꽃 끝의 열기가 줄고 전용 반쯤 감긴 픽셀 눈으로 피로를 표현한다. 얼굴 비율과 몸체 불투명도는 유지한다. 한도 소진 시 대기 상태에서 잔불처럼 쉰다. 관측 한도가 15%p 이상 증가하면 기지개와 불꽃 회복 제스처가 발생한다. Codex의 최신 한도 중 가장 적게 남은 기간을 사용한다. 다른 제공자와 오래된/미확인 관측값에는 정상 활력을 적용한다.

캐릭터 공간에서 주변 커서를 매 프레임 읽어 시선과 고개를 움직인다. 빠른 통과는 불꽃을 바람처럼 휘게 하며, 머리 위에서 천천히 움직이면 눈을 가늘게 뜨고 불티를 낸다. 빠른 접근은 최소 4초 간격으로 움찔 반응한다. 기존 클릭/드래그 입력 영역은 유지한다.

대기 중 12초 이후 불씨 잡기, 불꽃 정돈, 불꽃 하품을 서로 다른 간격에 보여준다. 세 동작을 한 차례씩 보인 뒤 순서를 섞는다. 55초 이상 대기하면 망치를 얼굴 아래 옆으로 내려놓고 전용 감은 눈으로 졸기 시작한다. 휴식 자세는 부드럽게 전환하며 진행 중인 망치질을 마친 뒤 적용한다. 동작 줄이기 설정은 모션과 불티를 모두 멈추고 정적인 색과 체력 표현을 유지한다.

설정의 정령 동작 확인 창에서 7가지 상태, 잔여 한도, 느리게 보기, 동작 줄이기를 확인할 수 있다. 이어보기에는 상태별 동작과 한도 감소/회복이 포함된다.

세션 미관측 물음표는 표시하지 않는다. 나머지 상태 표시는 몸체와 겹치지 않도록 이름표 옆에 배치한다.

검증: SpiritCore 테스트 166개, Xcode Debug 빌드, 실제 SpriteKit 렌더링 검사 및 상태별 PNG 11장과 128·192pt × 정상·피로·소진·휴식 × 밝은·어두운·패턴 배경 비교 PNG 24장. 별도 lint 설정은 없으며 Swift 빌드가 타입 검사를 수행한다.
