# 불꽃정령 동작·표현 시나리오

2026-09-21 · 구현 전 검토용 초안

## 캐릭터의 중심

**성실하지만 조금 서툴고, 일을 마치면 은근히 자랑하고 싶은 작은 대장장이.**

사용자가 느꼈으면 하는 인상은 “내 옆에서 자기 일을 열심히 하는 작은 친구”다.
기본 원화와 불꽃·망치라는 정체성은 유지한다. 귀여움은 큰 눈이나 많은 이펙트보다
무언가를 발견하고, 생각하고, 행동하고, 그 결과에 반응하는 순서에서 만든다.

성격은 세 가지 행동 원칙으로 표현한다.

- 성실함: 일을 시작하면 작업 지점을 보고 준비한다. 일을 마치면 결과를 확인한다.
- 작은 서투름: 불씨를 놓치거나 망치를 고쳐 잡는다. 실제 작업 오류를 장난으로 표현하지 않는다.
- 조용한 자랑: 완료 후 사용자 쪽을 잠깐 바라본다. 클릭이나 칭찬을 요구하지 않고 스스로 쉰다.

## 표현의 공통 문법

- 눈이 관심 대상을 먼저 찾고, 고개와 몸이 따라간다. 눈·고개·몸을 동시에 같은 비율로 움직이지 않는다.
- 중요한 자세는 짧게 유지한다. 쉬지 않고 흔드는 동작으로 정지를 채우지 않는다.
- 불꽃은 감정과 몸의 움직임을 따라 반응한다. 얼굴보다 먼저 시선을 빼앗지 않는다.
- 몸이 눌리면 조금 넓어지고, 늘어나면 조금 좁아진다. 얼굴은 과도하게 찌그러뜨리지 않는다.
- 큰 행동은 한 번에 하나다. 호흡과 작은 불꽃 흐름만 배경으로 계속 남긴다.
- 소리와 말풍선 없이도 장면을 이해할 수 있어야 한다. 소리는 기본 꺼짐을 유지한다.
- 아래 시간은 첫 프로토타입의 목표값이다. 실제 표시 크기에서 읽히는지를 보고 조정한다.

## 장면 1 — “응? 나 불렀어?”

**역할:** 가장 자주 보게 될 첫 교감. 사용자 존재를 알아차린다는 느낌.

**시작 조건:** 대기 중 커서가 주변 영역에 새로 들어오고 잠깐 머문다. 단순 통과와 구별한다.

| 시간 | 연기 |
|---|---|
| 0.00–0.18초 | 몸은 그대로 두고 눈만 커서를 향한다. |
| 0.18–0.45초 | 고개가 조금 늦게 기울어진다. 망치는 안정적으로 쥐고 있다. |
| 0.45–1.00초 | 눈을 또렷하게 뜨고 응시한다. 불꽃 끝이 고개를 따라 느리게 기운다. |
| 이후 | 커서가 머물면 작은 시선 추적만 유지한다. 떠나면 고개를 먼저 풀고 시선을 정면으로 돌린다. |

표정은 작은 미소와 열린 눈이다. 놀란 입이나 불티 폭발은 사용하지 않는다.
머리를 기울일 때 몸의 무게중심은 유지해 종이 전체가 회전하는 인상을 피한다.

반복 제어: 영역을 나갔다 다시 들어와도 약 4초 동안은 큰 고개 반응을 반복하지 않는다.
작업 중에는 짧은 곁눈질만 하고 작업 지점으로 돌아간다.

**성공 기준:** “마우스 때문에 움직였다”와 “나를 쳐다본다”가 작은 크기에서도 읽힌다.

## 장면 2 — “좋은데, 조금만 더…”

**역할:** 사용자가 다시 만지고 싶어지는 대표 상호작용.

**시작 조건:** 머리 위를 적당한 속도로 연속해서 쓸어준다. 정지한 커서만으로는 시작하지 않는다.

| 시간 | 연기 |
|---|---|
| 0.00–0.25초 | 손길을 눈으로 알아차리고 잠깐 고개를 멈춘다. |
| 0.25–0.70초 | 눈이 편안한 웃는 곡선으로 바뀐다. 입꼬리가 올라가고 몸이 조금 낮아지며 넓어진다. |
| 0.70초 이후 | 머리를 손길 쪽으로 살짝 기댄다. 빈손을 배 가까이 모으고 불꽃이 둥글고 잔잔해진다. |
| 손길 종료 후 0.00–0.35초 | 만족한 자세를 잠깐 유지한다. 즉시 기본 표정으로 바꾸지 않는다. |
| 손길 종료 후 0.35–0.90초 | 한쪽 눈을 먼저 뜨듯 짧게 확인하고, 작은 미소를 남긴 채 기본 자세로 돌아간다. |

망치는 손에서 놓지 않고 몸 옆으로 편안하게 낮춘다. 반복적인 하트 방출보다 얼굴과 자세를 우선한다.
피곤한 눈과 만족한 눈은 다른 원화를 사용한다. 불꽃의 기본 색은 유지한다.

반복 제어: 쓰다듬는 동안 첫 반응을 재시작하지 않고 만족 상태를 유지한다.
작업 중에는 타격 동작을 끝낸 뒤 짧은 눈웃음으로만 반응하고 작업을 계속한다.

**성공 기준:** 쓰다듬기와 졸림을 말풍선 없이 구별할 수 있고, 손길을 멈춘 뒤에도 짧은 여운이 남는다.

## 장면 3 — “어어? 나 어디 가?”

**역할:** 불꽃의 말랑한 재질과 망치의 무게를 보여주는 드래그 반응.

**시작 조건:** 클릭 임계거리를 넘어 실제 드래그가 시작된다. 단순 클릭·길게 누르기와 구별한다.

| 구간 | 연기 |
|---|---|
| 들어 올린 직후 약 0.15초 | 눈이 동그래지고 입이 작게 열린다. 짧은 놀람이 먼저 보인다. |
| 이동 중 | 몸 아래가 살짝 늘어나고 발이 모인다. 불꽃 끝은 이동 반대 방향으로 뒤따른다. |
| 잡은 채 정지 | 몸은 들어 올린 자세를 유지한다. 관성만 가라앉는다. |
| 놓은 직후 0.00–0.18초 | 내려앉으며 몸이 짧고 넓어지고, 망치를 쥔 손도 충격을 흡수한다. |
| 놓은 뒤 0.18–0.65초 | 한 번 작게 반동한 뒤 안정된다. |
| 놓은 뒤 0.65–1.10초 | 망치를 고쳐 잡고 사용자 쪽을 잠깐 본 뒤 평상 표정으로 돌아간다. |

빠른 이동도 변형의 상한을 넘지 않는다. 계속 흔든다고 눈·몸의 떨림을 무한히 키우지 않는다.
망치 금속은 늘어나지 않고, 손의 연결 지점만 몸을 따라 움직인다.
실제 창 이동은 입력을 즉시 따라가야 하며, 캐릭터 연기 때문에 위치 추적이 늦어지면 안 된다.

중단 규칙: 숨김·크기 변경·앱 비활성에 따른 드래그 취소에서는 튀는 착지 없이 안전하게 기본 자세로 정리한다.

**성공 기준:** 이동과 놓기가 구별되고, 불꽃·발·망치가 창 밖에서 잘리지 않는다.

## 장면 4 — “좋아, 만들어볼까.”

**역할:** AI 작업과 대장장이 설정을 연결하는 일상 행동.

**시작 조건:** 실제 작업 상태가 대기에서 작업 중으로 바뀐다.

| 구간 | 연기 |
|---|---|
| 시작 0.00–0.25초 | 눈이 작업 지점을 향하고 미소가 작은 집중 표정으로 바뀐다. |
| 시작 0.25–0.55초 | 발을 안정시키고 망치를 고쳐 잡는다. 불꽃이 위로 모인다. |
| 첫 타격 | 짧게 준비한 뒤 빠르게 내려친다. 몸의 압축과 불티는 접촉 순간에 맞춘다. |
| 반복 | 가벼운 두 번 → 작업물 확인 → 힘주는 한 번처럼 한 묶음의 리듬을 만든다. |
| 긴 작업 | 같은 리듬만 계속 반복하지 않고 가끔 자세를 고쳐 잡는다. |

타격 지점에 작은 고정된 받침/금속 조각을 보여줘 망치질의 대상을 읽을 수 있게 한다.
작업이 끝나면 도구와 함께 정리한다. 실제 AI 진행률을 알 수 없다면 작업물의 완성도를 진행률처럼 표시하지 않는다.

피로할수록 준비와 확인이 조금 느려진다. 피로도 때문에 실제 작업 성공/실패가 달라지는 것처럼 표현하지 않는다.
매 타격에 큰 불티를 내지 않고 강한 타격에만 강조를 둔다.

**성공 기준:** 무한 반복 GIF보다 작업에 집중하는 인상을 주고, 타격 위치가 분명하다.

## 장면 5 — “다 만들었어. 어때?”

**역할:** 구매 소개 영상의 중심이 될 대표 완료 연기.

**시작 조건:** 실제 작업 완료 이벤트. 진행 중인 타격은 마지막 회복까지 마무리한다.
아래 시간은 타격이 끝난 이후부터 센다.

| 시간 | 연기 |
|---|---|
| 0.00–0.35초 | 망치를 낮추고 결과를 내려다본다. 몸이 조용히 멈춰 완료를 읽을 틈을 준다. |
| 0.35–0.65초 | 눈이 조금 커지고 입꼬리가 올라간다. “잘됐네”라는 짧은 깨달음. |
| 0.65–0.85초 | 살짝 웅크린다. 불꽃도 잠깐 낮아진다. |
| 0.85–1.20초 | 짧게 폴짝 뛴다. 빈손을 들고 작은 불씨가 한 번 피어난다. |
| 1.20–1.45초 | 착지 충격을 몸으로 흡수한다. 불꽃은 한 박자 늦게 가라앉는다. |
| 1.45–2.30초 | 사용자 쪽을 바라보며 가슴을 살짝 펴고 뿌듯하게 웃는다. |
| 2.30–3.00초 | 손을 내리고 작은 미소를 남긴 채 쉰다. |

말풍선을 사용한다면 “다 만들었어!” 한 번으로 충분하다. 칭찬 요구·반복 호출은 하지 않는다.
새 작업이 시작되면 즉시 작업 연기로 전환하고, 드래그나 누르기로 중단한 완료 연기는 다시 이어 재생하지 않는다.
사용자가 드래그 중일 때 완료되면 완료 상태/알림은 전달하되 점프를 뒤늦게 예약하지 않는다.

**성공 기준:** “끝났다”와 “뿌듯해한다”가 함께 전달된다. 아무 반응을 하지 않아도 자연스럽게 끝난다.

## 장면 6 — “잡았다… 어?”

**역할:** 가끔 보고 웃을 수 있는 정령만의 작은 에피소드.

**시작 조건:** 건강한 대기 상태에서 사용자가 관여하지 않는 동안 가끔 실행한다.

| 시간 | 연기 |
|---|---|
| 0.00–0.45초 | 떠오르는 작은 불씨 하나를 눈으로 발견한다. |
| 0.45–0.80초 | 고개가 따라가고 빈손이 받을 준비를 한다. |
| 0.80–1.15초 | 손을 뻗지만 불씨가 조금 더 위로 떠오른다. |
| 1.15–1.55초 | 손을 편 채 잠깐 멈추고 눈만 위를 본다. |
| 1.55–2.15초 | 불씨가 내려오면 손바닥으로 살며시 받는다. |
| 2.15–2.65초 | 불씨와 사용자를 번갈아 보며 작게 웃는다. |
| 2.65–3.20초 | 불씨를 놓아 보내고 평상 자세로 돌아온다. |

불씨는 처음부터 손에 붙어 나타나지 않는다. 눈·손·불씨가 같은 목표를 따라야 한다.
실패를 여러 번 반복하거나 과장된 슬픔을 표현하지 않는다.

반복 제어: 초기 후보 간격은 25–45초. 망치 놀이와 같은 큰 대기 행동 중 하나만 선택한다.
같은 행동이 바로 반복되지 않게 한다. 오랫동안 조작이 없으면 대기 행동 빈도를 줄이고 휴식으로 넘어간다.

**성공 기준:** 불씨를 보고 잡는 작은 이야기가 자막 없이 이해된다.

## 장면 7 — “잠깐, 이것 좀 봐줄래?”

**역할:** 확인 요청과 오류를 귀여움 때문에 혼동하지 않도록 표현한다.

**확인 요청:** 망치를 낮춤 → 사용자 쪽으로 시선 이동 → 고개를 기울임 → 작은 불씨를 손바닥에 올려 내밈.
약 1초에 걸쳐 요청 자세를 만들고, 이후에는 차분하게 기다린다. 계속 팔을 흔들지 않는다.

**오류:** 짧게 움찔함 → 작업 지점을 확인함 → 망치를 멈추고 사용자 쪽을 봄.
놀람은 한 번만 표현하고 이후에는 안정된 걱정 표정으로 유지한다. 끝없이 떨지 않는다.

확인 요청에는 호기심/기다림, 오류에는 놀람 이후의 걱정을 사용한다.
정확한 원인과 필요한 조치는 대시보드 또는 짧은 안내에서 전달한다.

**성공 기준:** 오류를 작업 완료나 장난으로 오해하지 않으며, 해결 전까지 상태가 유지된다.

## 장면 8 — “잠깐 쉬었다 할게.”

**역할:** 조용히 함께 있는 시간에도 캐릭터가 자연스럽게 존재하도록 한다.

**시작 조건:** 장시간 대기 또는 실제 한도 상태에 따른 피로. 사용자가 떠났다는 이유로 슬퍼하지 않는다.

눈 깜빡임이 느려짐 → 약 1초 동안 작은 하품 → 망치를 몸 옆으로 낮춤 → 몸이 둥글게 내려앉음 → 작은 호흡만 남김.
전체 진입은 약 3초이며, 잠든 뒤 큰 대기 행동은 실행하지 않는다.

사용자 입력이나 작업 시작으로 깨어날 때는 눈을 먼저 뜨고 약 0.5초에 걸쳐 몸을 편다.
명시적인 수면 상태와 단순 대기 졸림의 해제 조건은 실제 앱 상태와 연결한다.
한도 회복은 작은 기지개로 표현하되 충전 결제나 추가 사용을 요구하는 연기는 하지 않는다.

**성공 기준:** 피로해도 불쌍하거나 고장 난 인상보다 편안히 쉬는 인상을 준다.

## 필요한 표정과 포즈

| 표현 | 사용 장면 | 형태의 기준 |
|---|---|---|
| 평상 | 대기, 복귀 | 열린 눈, 작은 미소 |
| 호기심 | 커서 발견, 불씨 발견 | 시선 이동, 고개 기울임, 입은 작게 유지 |
| 집중 | 작업, 결과 확인 | 시선 아래, 눈꺼풀을 살짝 낮춤. 화난 눈썹은 피함 |
| 만족 | 쓰다듬기 | 웃는 눈 곡선, 편안한 입, 낮고 둥근 몸 |
| 놀람 | 들어 올림, 순간 오류 | 열린 눈과 작은 둥근 입, 짧게 늘어난 몸 |
| 뿌듯함 | 완료, 불씨 잡기 | 만족 얼굴을 공유하되 가슴·팔·시선으로 구별 |
| 걱정/요청 | 오류, 확인 필요 | 눈과 입의 작은 비대칭, 안정된 자세 |
| 졸림 | 휴식 | 만족과 다른 눈꺼풀, 하품 입, 힘을 뺀 몸 |

8개의 독립적인 전신 원화를 모두 만들 필요는 없다. 공통 눈·입 조각과 몇 개의 핵심 포즈를 재사용한다.
망치는 단단한 물체, 몸은 말랑한 불꽃, 불꽃 끝은 뒤늦게 따라오는 부분으로 움직임을 구별한다.

## 행동 연결 규칙

1. 사용자 드래그와 누르기가 시작되면 장난·완료 연기를 정리한다. 중단된 연기를 나중에 재생하지 않는다.
2. 새 작업·오류·확인 요청은 대기 행동보다 우선한다. 상태 안내는 즉시 바꾸고, 들려 있는 망치는 안전하게 회수한다.
3. 완료 연기는 한 이벤트에 한 번만 실행한다. 상태가 대기로 바뀌어도 진행 중인 연기는 끝낼 수 있지만 새 작업이 오면 중단한다.
4. 쓰다듬기와 망치 놀이는 겹치지 않는다. 작업 중 쓰다듬기는 얼굴의 짧은 반응만 허용한다.
5. 불씨 놀이·하품·망치 놀이는 하나의 대기 행동 순서에서 선택한다. 서로의 타이머를 계속 초기화해 영원히 시작하지 못하는 구조를 피한다.
6. 소진/수면에서는 큰 장난과 점프를 억제한다. 완료의 의미는 정적인 표정이나 안내로도 전달한다.
7. 동작 줄이기에서는 흔들림·늘어남·점프·불티를 멈추고 각 상태의 표정과 안내를 유지한다.
8. 긴 프레임 지연 후 여러 연기나 이펙트를 몰아서 재생하지 않는다.

## 구현 순서

### 1차: 구매 영상에 쓸 세 장면

장면 2 쓰다듬기, 장면 3 드래그, 장면 5 완료를 먼저 완성한다.
현재 구현에는 이 세 장면의 기본 반응이 있으므로 다음 차이를 보강한다.

- 쓰다듬기: 만족 진입 전 알아차림, 손길을 멈춘 뒤의 여운과 눈 뜨기.
- 드래그: 얼굴과 몸·도구의 재질 구별, 착지 후 망치를 고쳐 잡는 마무리.
- 완료: 결과 확인과 짧은 깨달음의 정지, 사용자 쪽을 보는 뿌듯한 여운.

### 2차: 일상 행동의 설득력

장면 1 시선 반응, 장면 4 작업 리듬, 장면 8 휴식을 연결한다.
기본 대기 움직임의 양은 줄이고 필요한 순간의 대비를 키운다.

### 3차: 성격과 상태 구별

장면 6 불씨 에피소드와 장면 7 확인/오류를 완성한다.
의상·여러 스킨·수집·성장 기능은 이번 동작 시나리오의 범위에 포함하지 않는다.

## 검증 방법

- 각 장면을 실제 80/128/192pt와 밝은/어두운 배경에서 확인한다. 얼굴·불꽃 끝·망치가 잘리지 않아야 한다.
- 정지 화면만 보지 않고 시작·유지·종료를 포함한 영상으로 비교한다.
- 30/60/120fps에서 입력 반응의 강도와 행동 시간이 크게 달라지지 않는지 확인한다.
- 드래그 중 완료, 점프 중 새 작업, 쓰다듬기 중 숨김, 습관 중 오류를 재현해 중단과 복귀를 검사한다.
- 목표 사용자에게 장면 이름 없이 짧은 영상을 보여주고 “무슨 일이 있었나”, “어떤 기분 같나”를 묻는다.
- 이어서 실제로 며칠 사용하게 하고 다시 만져보고 싶은 행동과 방해되어 끄게 된 순간을 확인한다.
- 테스트 통과는 렌더링·상태 연결의 증거다. 귀여움과 구매 의사는 사용자 반응으로 별도 판단한다.

## 15초 소개 영상 구성

0–3초: 정령이 커서를 알아보고 고개를 기울인다.

3–6초: 머리를 쓰다듬자 눈웃음을 짓고 손길에 기댄다.

6–10초: 작업 지점을 보고 짧은 리듬으로 망치질한다.

10–13초: 마지막 타격 후 결과를 확인하고 폴짝 뛴다.

13–15초: 사용자 쪽을 보며 뿌듯하게 웃고 조용히 쉰다.

영상의 한 문장: **“같이 만들고, 같이 뿌듯해하는 작은 불꽃 대장장이.”**
