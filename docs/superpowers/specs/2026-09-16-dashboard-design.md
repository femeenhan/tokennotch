# 픽셀 작업 대시보드 승인 설계

승인: 2026-09-16 대화에서 사용자가 첫 버전 범위와 픽셀 디자인을 승인했다.

macOS14+, Swift6, SwiftUI/AppKit, SpriteKit 기존 앱에 대시보드를 추가한다. 밝은 바탕과 시스템 다크 모드, 각진 2px 테두리와 단단한 그림자, 정령의 주황 강조색을 사용한다. 숫자와 짧은 영문은 monospace, 긴 한글은 시스템 sans로 읽기 쉽게 표현한다. 참고: https://makebead.com/ko/patterns/p/red-rose-34e6879bb7fdb014 . 디자인 강도: variance5, motion3(정령 제외), density5. 웹 디자인 프레임워크나 서버를 도입하지 않는다.

상단에 작은 정령·현재 연결 상태·작업/확인요청 세션 수. 중앙에 오늘/7일/30일 필터, 일별 이벤트 격자, 등록 프로젝트 필터와 세션 목록. 선택한 세션에는 상태·최종 관측 시각·작업 시작/도구/확인요청/턴종료 타임라인·토큰 수집상태를 표시한다. 데이터는 앱이 받은 실제 이벤트와 사용자가 명시적으로 선택한 로그에서 추출한 usage 메타데이터만 사용한다. 데모와 실데이터는 섞지 않는다.

이벤트와 프로젝트 연결, 토큰은 로컬 SQLite에 저장한다. 단일 actor, WAL, migration version, 사용자 전용 경로/권한. eventID와 usage sourceRecordID 중복을 제거한다. 재시작 후 진행 상태는 unknown이며 종료는 완료/성공과 구분한다. 오래된 관측을 완료로 추론하지 않는다. 도구 횟수는 시작 이벤트 수, 활동 칸은 이벤트 수이며 생산성 점수가 아니다. 기간은 로컬 캘린더 날짜, 합계와 목록에 동일한 필터를 적용한다. 사용량 미수집과 실제0을 구분하고 cache/reasoning 포함관계를 보존한다. 프로젝트를 폴더로 등록하고 세션을 수동 연결할 수 있어야 한다. 현행 hook은 프로젝트 경로를 보내지 않으므로 무단 home 스캔이나 추론을 하지 않는다.

토큰은 앱에서 명시적으로 JSONL 로그를 선택한 경우에만 접근한다. 선택된 파일의 증분읽기·부분 마지막 행·파일교체·오류를 처리한다. 원문은 메모리에서 일시 해석할 수 있지만 프롬프트·응답·코드·명령·patch를 DB/로그에 저장하지 않는다. 첫 버전은 연결 이전 로그 자동수집을 하지 않으며, 파일선택 UI에서 해당 파일의 기존 메타데이터를 가져오는 동의를 설명한다. 수집 해제를 제공하고 관측불가/형식변경은 기록없음 또는 오류로 표시한다. 비용 환산/구독한도 추정/Git 커밋 연결/Claude는 제외한다.

저장 실패가 캐릭터 반응과 CLI 작업을 막으면 안 된다. 오류·미연결·빈 목록·선택없음 상태를 구현한다. JSON 메타데이터 내보내기를 제공한다. 사용자 기록을 자동 삭제하지 않으며 30일 화면범위와 별개로 보존정책은 명확히 표기한다. 렌더링 숨김·입력영역·알림기능 보존. 대시보드 미리보기는 live 상태를 조작하지 않는다.

검증: sqlite 재실행·100회 중복·기간/프로젝트 필터·민감정보 제거·부분행/교체 usage fixture 테스트, Xcode Debug 빌드, 기존 bridge/app integration, 실제 창의 필터·세션 선택·설정·창 종료/재열기 검증. 공개 배포/아이콘/공증은 이번 범위 아님.
